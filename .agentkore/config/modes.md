# AgentKore Modes

## fast
Use `fast-bmad` and `change-test-loop`. Best for clear, small tasks.

## balanced
Use `agent-flow`, short planning, task execution, tests, and review. Best default for multi-file work.

## deep
Use `ak-elicit`, `ak-party`, PRD/tasks, session tracking, secure review, and release checks. Use only for high-risk or enterprise work.
