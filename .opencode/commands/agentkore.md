description: Start AgentKore using the smallest safe workflow
---

Load `agent-flow` and `agent-contract`.

Then:
1. Inspect `AGENTS.md` and `.agentkore/config/agentkore.json`.
2. Choose the smallest safe workflow for the user request.
3. Load only the required skills.
4. Do real work only; never simulate tool results.
5. Verify and report using the AgentKore final format.
