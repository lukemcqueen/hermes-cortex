## Documentation check (before creating/updating docs)
Load `doc-system`. List docs, search keywords, identify existing/related docs, decide update, extend, or create new.

## Memory check (before persisting durable memory)
Load `memory-management`. Score durability, reuse, non-obviousness, and risk if forgotten. Write only when total score ≥ 7.
