# Evidence — remove ~/.hermes/AGENTS.md sync, AGENTS is per-repo (2026-11-04)

Change: cycle 8154. The fleet deploy (cortex-update.sh), the doctor
(checks.py), and the pre-commit hook (pre-commit-score) previously enforced a
global copy of the repo AGENTS.md at ~/.hermes/AGENTS.md. This change removes
that coupling: AGENTS.md lives ONLY in each repo, seeded from the fleet
template (docs/templates/AGENTS.seed.md via seed-project.sh). claude agents
already use per-repo CLAUDE.md.

## 5. Hermes reads AGENTS.md per-repo (cwd), not from ~/.hermes

Hermes-agent skill, references/project-context-files.md:
    "AGENTS.md / agents.md: Cwd only — subdirectory and parent copies are
     ignored"
    "Don't put project rules in ~/.hermes/AGENTS.md (or any other home-level
     location)... For cross-project context, use SOUL.md"

So ~/.hermes/AGENTS.md was fleet-tooling only (cortex-update wrote it; doctor
+ pre-commit validated it) and only ever loaded in a session whose cwd was
~/.hermes — a degenerate, non-project cwd. Removing it aligns WITH Hermes's
own documented contract. Removed global copy loses no project-scoped rules;
fleet-template rules reach agents via each repo's seeded AGENTS.md.

## Blast radius of the removal

Removed (the ~/.hermes/AGENTS.md coupling):
- cortex-update.sh: the AGENTS.md -> ~/.hermes sync block.
- checks.py: `AGENTS.md (~/.hermes)` missing-FAIL / size / `AGENTS.md sync`
  content-marker checks, plus the dead `_extract_agents_markers` helper and
  the `hermes_agents`/`repo_agents` ephemeral vars.
- pre-commit-score: the hard `~/.hermes/AGENTS.md` existence + rule-count
  gate, replaced by a per-repo own-AGENTS.md check.

Kept (the per-repo design):
- check_dev_repo_agents (dev repos have AGENTS.md), check_dev_repo_claude
  (claude agents), seed-project.sh, AGENTS.seed.md, and the orchestor-only
  `AGENTS.md` entry.
- SOUL.md remains at ~/.hermes/SOUL.md (identity layer; unchanged).
