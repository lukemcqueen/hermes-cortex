=== 8. What this proof does NOT cover ===
- macOS. The extension shells out to a resolved python3 and is overridable via
  CORTEX_GOVERNANCE_PYTHON for a Homebrew python off pi's PATH; that path is
  untested here.
- Only one direction of the repo-scoping rule is exercised LIVE above (a peer's
  lock does not cover us). The same-NAME / different-project case is pinned by a
  committed unit test rather than live, because constructing it needs a lock with
  no recorded repo_path, and hand-writing a lock file is a governance violation.
