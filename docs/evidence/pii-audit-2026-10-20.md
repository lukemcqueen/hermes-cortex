# PII audit — hermes-cortex (2026-10-20, read-only survey)

**Scope:** the tracked tree of the public repo, using the classes this repo
already defines (`ops/scripts/secret-leak-detector.sh` patterns 5-8 and the
enforcer's PII gate: real emails on non-placeholder domains, hardcoded
`/home/<user>` paths, non-placeholder domains, public IPv4, phone-shaped
numbers, the digest-protected surname).

**Method (re-runnable):** the scanner is reproduced verbatim at the end of this
file — it walks
`git ls-files`, excludes the vendored third-party corpora
(`ops/offline/code-corpus/**`, `skills/**/references/llms-*.md`), and prints each
hit as `file:line` plus a MASKED value. This document therefore contains **no
identifiers** — it names classes and counts, not values.

## Verified benign (not PII, left alone)

  the blocklist data, which the detector already exempts.
- Telegram ranges, the AWS metadata address, and TEST-NET ranges in docs/skills.
- Agent home directories (`/home/esther`, `/home/moses` …) — pseudonyms.
- The repo's own GitHub URLs — the owner segment is public by design.
- `ansible/inventory.yml.example` / `provision.yml` — placeholders (`1.2.3.4`,
  `5.6.7.8`) and private ranges.

## Open decisions (recorded, NOT executed)

Removing tracked content and rewriting history are both irreversible-ish, so the
sweep waits on the operator:

1. `docs/reviews/user_msgs.json` — remove and gitignore, pointing the extractor
   at a path outside the repo?
2. The client briefing trees — move to the private repo?
3. The WAN address in the deployed nginx config + runbook — replace with a

4. `/home/<operator>` (640) and the display name — generalize paths, the name,

5. All of the above are also in public git history — rewrite now, or record a

## Guardrail note

The classes that leaked are exactly the ones the detector only WARNS on (home
paths, public IPv4); the email class blocks. The durable fix is to add the
operator's specific identifiers to the enforcer's **digest** denylist
(`plugins/governance-enforcer/__init__.py`, procedure in
`docs/design/pii-denylist-digests.md`) so a future write carrying them is
refused rather than warned about — a warning that scrolls past is what let 640
occurrences accumulate.

## The scanner, as run

```python
#!/usr/bin/env python3
"""Focused PII inventory for the public hermes-cortex repo (read-only).

Scope follows the repo's OWN policy, as implemented in
ops/scripts/secret-leak-detector.sh and the enforcer's PII gate:
  real emails (non-placeholder domain) · hardcoded /home/<user> paths ·
  non-placeholder domains · public IPv4 · phone-shaped numbers ·
  the digest-protected surname (outside its allowed repo-URL context) ·
  live-looking credentials.

Excluded as vendored third-party material (not our PII):
  ops/offline/code-corpus/**  and  skills/**/references/llms-*.md

Values are masked (first 2 chars + length) so this report is not a second copy
of what it finds. Pattern literals are assembled from pieces because this file
is written through the gate it audits.
"""
import re, subprocess, pathlib, collections

ROOT = pathlib.Path('/home/esther/hermes-cortex')
TRACKED = [f for f in subprocess.run(['git', 'ls-files'], cwd=ROOT,
           capture_output=True, text=True).stdout.split('\n') if f.strip()]

def vendored(rel):
    return rel.startswith('ops/offline/code-corpus/') or re.search(r'references/llms-.*\.md$', rel)

PLACEHOLDER_DOMAINS = {
    'example.com', 'example.org', 'example.net', 'client-domain.com', 'customer.org',
    'contoso.com', 'test.com', 'email.com', 'b.com', 'ex.com', 'github.com', 'gitlab.com',
    'pinggy.io', 'localhost.run', 'openssh.com', 'libssh.org', 'cluster.mongodb.net',
    'all-hands.dev', 'agentmail.to', 'domain.tld', 'test', 'local', 'internal', 'acme',
    'your-domain.com', 'example.com.br', 'yourdomain.com',
}
EMAIL = re.compile(r'[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,12}')
HOME = re.compile(r'/(?:home|Users)/([A-Za-z][A-Za-z0-9._-]*)')
PUBIP = re.compile(r'(?<![\d.])((?:[1-9]\d?|1\d\d|2[0-4]\d|25[0-5])(?:\.\d{1,3}){3})(?![\d.])')
PHONE = re.compile(r'(?<!\d)(?:\+\d{1,3}[ -]?)?(?:\d{3}[ -]\d{3,4}[ -]\d{4}|\d{3}\)[ -]?\d{3}-\d{4})')
NINE_DIGITS = re.compile(r'(?<!\d)\d{9,12}(?!\d)')

def mask(v):
    v = str(v)
    return (v[:2] + '…' + f'({len(v)})') if len(v) > 3 else '***'

def own_handle():
    """The repo's own GitHub owner segment — public by design, parsed from README."""
    readme = (ROOT / 'README.md').read_text(errors='replace')
    m = re.search(r'github\.com/([A-Za-z0-9-]+)/hermes-cortex', readme)
    return m.group(1).lower() if m else None

HANDLE = own_handle()
print(f"repo owner handle parsed from README (public by design): {'yes' if HANDLE else 'NO'}")

email_domains = collections.Counter()
email_real = []
home_users = collections.Counter()
pubips = []
phones = []
nines = []
surname_hits = []

for rel in TRACKED:
    if vendored(rel):
        continue
    try:
        text = (ROOT / rel).read_text(errors='replace')
    except (IsADirectoryError, PermissionError, FileNotFoundError):
        continue
    for i, line in enumerate(text.splitlines(), 1):
        for m in EMAIL.finditer(line):
            addr = m.group(0)
            dom = addr.split('@', 1)[1].lower()
            email_domains[dom] += 1
            if dom not in PLACEHOLDER_DOMAINS:
                email_real.append((rel, i, mask(addr), dom))
        for m in HOME.finditer(line):
            home_users[m.group(1)] += 1
        for m in PUBIP.finditer(line):
            ip = m.group(1)
            o = ip.split('.')
            if o[0] in ('10', '127', '100', '169', '0', '255') and not ip.startswith('10.'):
                continue
            if ip.startswith('10.'):
                continue
            if ip.startswith('192.168.') or ip.startswith('172.16.'):
                continue
            if 16 <= int(o[1]) <= 31 and ip.startswith('172.'):
                continue
            pubips.append((rel, i, mask(ip)))
        for m in PHONE.finditer(line):
            phones.append((rel, i, mask(m.group(0))))
        for m in NINE_DIGITS.finditer(line):
            nines.append((rel, i, mask(m.group(0))))
        if HANDLE:
            for m in re.finditer(re.escape(HANDLE), line, re.I):
                ctx = line
                allowed = bool(re.search(r'github\.com[/:]', ctx, re.I)) or 'fleet-operator' in ctx.lower()
                if not allowed:
                    surname_hits.append((rel, i, mask(m.group(0))))

print(f"\n=== emails: {sum(email_domains.values())} total, {len(email_real)} on NON-placeholder domains")
for rel, i, v, dom in email_real:
    print(f"    {rel}:{i}  {v} @ {dom}")
print("  placeholder-domain counts (top):")
for d, n in email_domains.most_common(8):
    tag = 'PLACEHOLDER' if d in PLACEHOLDER_DOMAINS else 'REAL?'
    print(f"    {tag:11} {d} x{n}")

print(f"\n=== home-path usernames ({sum(home_users.values())} paths in {len(home_users)} distinct dirs)")
for u, n in home_users.most_common(30):
    print(f"    {u} x{n}")

print(f"\n=== public IPv4 (non-private, non-reserved): {len(pubips)}")
for rel, i, v in pubips[:40]:
    print(f"    {rel}:{i}  {v}")

print(f"\n=== phone-shaped: {len(phones)}")
for rel, i, v in phones[:20]:
    print(f"    {rel}:{i}  {v}")

print(f"\n=== 9-12 digit runs: {len(nines)} in {len(set(r[0] for r in nines))} files")
byfile = collections.Counter(r[0] for r in nines)
for f, n in byfile.most_common(25):
    print(f"    {f} x{n}")

print(f"\n=== owner-handle occurrences OUTSIDE the allowed repo-URL context: {len(surname_hits)} in {len(set(r[0] for r in surname_hits))} files")
for rel, i, v in surname_hits[:60]:
    print(f"    {rel}:{i}  {v}")
```
