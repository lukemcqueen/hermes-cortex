# LinkedIn Profile Package — Deliverable Checklist & Conventions

## The deliverable set

A "full profile" request normally wants all of these; deliver them in this
order and label each with the platform's own section name:

1. Five headline options, each within the character limit.
2. The recommended headline + a one-paragraph reason it is strongest.
3. Full About section (first person).
4. Concise About section (roughly a third the length).
5. Current-role experience description (plus an alternate if the current
   employer is ambiguous in the source corpus).
6. Company/venture description for any business the user leads.
7. Skills, grouped by theme.
8. Open-to-Work positioning statement (recruiter-facing, first person).
9. Suggested Providing Services categories.
10. Recommendations for Featured / Projects / Accomplishments.
11. Short professional introduction to send with connection requests.
12. Search keywords recruiters and clients would use.

## Platform limits

| Element | Limit / convention |
|---|---|
| Headline | 220 characters (feeds truncate near 60–70) |
| About | ~2,600 characters; first 2 lines show before "see more" |
| Connection note | 300 characters |
| Job title field | 100 characters |
| Skills | 50 max, with 5 pinned as "top skills"; typed entities are what search matches |
| Providing Services | fixed pick-list, not free text — map to the closest existing categories and put specifics in the free-text service headline |
| Open to Work | has a recruiters-only mode |

Count characters with a tool before delivering an option list, and show the
count next to each headline.

## Headline structure that works

One primary identity first, then searchable terms, then location, then a
differentiating tail, then employer pedigree:

```
<primary role> · <searchable capability 1> · <searchable capability 2>
| <role descriptor> in <city, country> | <differentiated secondary
specialization> | Ex <recognizable employers>
```

Why: recruiter search is entity-driven. Splitting the headline across three
equal "I am also a…" identities dilutes match quality; the secondary
specialization belongs in the tail clause and fully in About. Employer brands
close the line because they carry instant credibility with enterprise buyers.

## Evidence rules

- Every client name, metric, date, and employer in the copy must trace to a
  source file in the career corpus. Flag the ones that do not — an unsupported
  defense/government client name in particular.
- Never state a technology the corpus does not show. Label older stacks as
  prior/legacy rather than listing them beside current ones.
- Confidential client work (individual coaching, internal figures) needs
  consent before it appears; state defense-adjacent work generally.
- Recommend, do not fabricate, the Featured artifacts: a sanitized architecture
  diagram, an observability/cost dashboard screenshot, a one-page PoC case study
  (problem → approach → result), a published rights/metadata writeup, a release
  or catalog credit. Empty Featured sections make a claimed capability read as
  a label rather than a record.
- Recommendations from real counterparties lift advisory positioning more than
  any copy edit — request them, with consent for anyone named.

## Ethics / governance thread (when requested)

Tie it to the user's existing work rather than importing framework jargon:
provenance and attribution, trace-level auditability of agent behaviour, human
review before consequential action, consent for source/training data, and
disclosure of where AI sits in the loop. Place it in About as a short
"making it practical" passage, echo it in the current-role bullets and the
venture description, and carry it as skills (AI Governance, Responsible AI, AI
Ethics, Data Provenance) plus search keywords. Frame as practiced principles —
never as a certification, standard, or badge the user does not hold.

## Profile hygiene checklist (deliver as ordered next steps)

1. Correct current title/company — every other section depends on it.
2. Confirm or drop unsupported claims.
3. Rewrite headline and About.
4. Experience with real dates; add Education and Languages.
5. Load Skills with the top 5 pinned.
6. Add Featured artifacts.
7. Enable Providing Services; set Open to Work to recruiters-only.
8. Request recommendations.
9. Custom URL, city-level location + remote, banner, headshot.
10. Only then post — periodic posts on the core topic keep the profile
    surfacing in search.
