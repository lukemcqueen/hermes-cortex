## Bus auth verification flow used

```bash
# 1. Health check (no auth)
curl -s http://localhost:8903/health
# → {"status":"ok","backend":"pgmq","queues":16,...}

# 2. Extract token from .env
TOKEN=$(grep '^CORTEX_BUS_TOKEN=' ~/hermes-cortex/.env | cut -d= -f2)

# 3. Check inbox depth
curl -s -H "Authorization: Bearer $TOKEN" \
  http://localhost:8903/api/pgmq/depth/inbox_moses
# → {"queue":"inbox_moses","depth":0}

# 4. Also try to read (returned null since empty)
curl -s -H "Authorization: Bearer $TOKEN" -X POST \
  http://localhost:8903/api/pgmq/read \
  -H "Content-Type: application/json" \
  -d '{"queue":"inbox_moses","vt":30,"limit":5}'
# → {"msg_id": null, "queue": "inbox_moses"}
```
