# prd-lite — PRD Template v1.0.0

## 1. Problem
What specific problem or opportunity are we solving? What evidence supports this?

## 2. Scope — In
Which features, capabilities, or changes are explicitly included in this work?

## 3. Scope — Out
What is explicitly **not** in scope to prevent scope creep?

## 4. Functional Requirements
Key functional behaviours the solution must implement. Bulleted, each testable.

## 5. Non-Functional Requirements
Performance, security, scalability, availability, maintainability constraints.

## 6. Edge Cases
Off-nominal inputs, error states, concurrent access, boundary conditions to handle.

## 7. Acceptance Criteria
Concrete pass/fail conditions that define "done" for this work.
