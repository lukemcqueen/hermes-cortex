# The Client Brand Brand Marketing Skill

**Brand snapshot:** Amy & Luke — Korean-American founders in Seoul. Riviera Summer Tote (canvas, water-repellent lining, drawstring, pockets) + matching pouch. ~1,400 IG followers. Tagline: *"Designed with Purpose. Guided by Faith."*

**When to load:** User asks about The Client Brand marketing — captions, content calendars, email sequences, brand voice, product storytelling, social media strategy, or content performance reviews.

---

## 1. Brand Voice & Storytelling Framework

**Voice pillars:** Purpose-first (lead with why) | Warm conviction (gentle confidence) | Craft honesty (show real making) | Faith naturally (personal, not preachy) | Cross-cultural lens (Korean-American in Seoul)

**Temperature guide:**
- Product launch → warm + clear, excited but not shouting
- Founder story → warm + open, vulnerable invitation
- BTS / education → warm + instructive, generous with knowledge
- Faith share → warm + reverent, personal testimony
- Customer share → warm + grateful, celebrate them

**Avoid:** Corporate jargon, fake urgency ("last chance!!!"), performative religiosity, stock photos, generic sustainability claims.

## 2. Social Media Content Strategy

**Platform roles:**
- **Instagram** — Visual storytelling hub, product showcase, community. Feed ~3x/wk, stories daily, reels 3-5x/wk.
- **TikTok** — Discovery engine, personality-driven. Daily 1-2 clips.
- **YouTube** — Deep-dive trust-building. Weekly 8-12 min episode.

**Content mix targets (monthly):** Founder story 25% | Product storytelling 25% | BTS/process 20% | Educational/value 15% | Community/UGC 10% | Sales/launch 5%

**Hashtag tiers (layer 3 per post):** ① Niche-brand (#The Client Brand #DesignedWithPurpose) ② Category (#SustainableFashion #SlowFashion #SeoulMade) ③ Discovery (#FaithDriven #CanvasTote #EcoFashion)

**90-day arc:** Foundation (wk 1-2, build audience) → BTS depth (3-4, build trust) → Pre-launch (5-6, build anticipation) → Launch (7-8, drive sales) → Post-launch (9-10, community) → Retrospective (11-12, retention)

## 5. Email Marketing Sequences

### Pre-Order Launch (6 emails)
| # | Timing | Subject Line | Content |
|---|--------|-------------|---------|
| 1 | Week before | "Something beautiful is coming" | Tease, personal note, don't reveal everything |
| 2 | Launch day, 2h early | "You're first — pre-order open" | VIP early access, short story, early-bird pricing |
| 3 | Launch day | "The [product] is here" | Full announcement, photos, features, shipping timeline |
| 4 | Day 5-7 | "People are loving the [product]" | Customer quotes, order milestones, social proof |
| 5 | Final 48h | "Last chance — closing [day]" | Scarcity, testimonial pull quote, timeline |
| 6 | Post-close | "Thank you + what's next" | Gratitude, production update, personal reflection |

### Welcome Sequence (3 emails)
| # | Subject | Content |
|---|---------|---------|
| 1 | "Welcome to The Client Brand 🤍" | Who we are, why the brand exists, reply-to-say-hi invite |

## 6. Product Storytelling Techniques

**7-slide carousel framework:**
| Slide | Content |
|-------|---------|
| 1 | Hero product shot — clean, well-lit |
| 2 | The problem — "I couldn't find a bag that [pain point]" |
| 3 | The solution — intro product + 1-2 key features |
| 4 | Detail close-up — material, stitch, hardware |
| 5 | The story — inspiration, design struggle, maker moment |
| 6 | Lifestyle — product in use, real setting |
| 7 | CTA — pre-order / link in bio |

**Product description formula:** [Name] — [one-line evocative description] | [Paragraph — problem + story] | [Paragraph — materials, construction, philosophy] | Bullet features (3, benefit-focused) | Details block (material, dimensions, care, origin) | [Tagline]

**Video product story arc (Reel/TikTok):** 0-2s hook ("This bag almost didn't exist") → 2-10s struggle (failed samples, factory search) → 10-20s breakthrough (the supplier, the insight) → 20-28s solution (product shots, features, use footage) → 28-30s CTA

## 7. Performance Review Framework

**Weekly (15 min):** Top 3 posts — commonalities? Bottom 3 — what didn't work? Follower change. Story engagement (polls, DMs). One adjustment for next week.

**Monthly (30 min) — track these:**
| Metric | Current | Prev Month | Trend |
|--------|---------|------------|-------|
| Followers | | | |
| Avg engagement rate | | | |
| Top content type | | | |
| Website clicks | | | |
| Email signups | | | |
| Sales / pre-orders | | | |

**Quarterly deep-dive questions:**
- Which format gave highest ROI per hour of effort?
- Which topics resonated most?
- Is content building awareness (reach, shares) or converting (clicks, sales)?
- Do comments reflect brand values back at you?
- Has voice stayed consistent?
- What one thing changes next quarter?

**Audit checklist:**
- [ ] Content mix hitting targets? (see §2)
- [ ] Every video's first 2 seconds a hook?
- [ ] Every product post has ≥1 benefit statement?
- [ ] Stories daily with ≥1 interactive element?
- [ ] Every YT thumbnail = face + text overlay?
- [ ] Cross-promoting platforms?
- [ ] UGC reposted in last week?
- [ ] Bio / link-in-bio current?

## Pitfalls

- Planning does not replace posting. Consistent imperfect output beats a perfect calendar with nothing published.
- Every video needs a compelling first 2 seconds. Every caption needs a compelling first line.
- Don't repeat the same hook twice in one week.
- Stories build relationship; feed posts build archive. Both are essential.
- Lead with value, not sales. If >5% of posts are sales-driven, audiences disengage.
- Keep voice consistent across platforms — overlapping audiences notice drift.
- Always review. Content without iteration is guessing. Review weekly, adjust monthly.
